## Для Claude Code

- Подробности читайте по задаче из `docs/ai/AI_*.md` (порядок — в `AGENTS.md`), а не все файлы сразу.
- Источник истины — код. Нашли расхождение документации с кодом — скажите пользователю и исправьте `docs/ai/` (английскую ветку `main` нужно будет обновить отдельно).
- После правки: `php tests/static-check.php`; на тестовом сайте — `wp eval-file tests/smoke-test.php`. Нет терминала или WordPress — скажите пользователю, что запустить и что проверить вручную.
- Задача про выбор города / несколько регионов — сначала `docs/ai/AI_EXTENDING.md`, раздел 13 (и вопрос про WP Multisite).
- Команды: `/check` — запустить `static-check` и объяснить результат; `/new-ajax <имя> <что делает>` — добавить AJAX-действие по чек-листу. После каждой правки PHP-файла хук (`.claude/settings.json`) сам запускает `php tests/static-check.php`; если он сообщил об ошибке — исправьте код, а не тест.
- Английская версия проекта — ветка `main` на GitHub.
