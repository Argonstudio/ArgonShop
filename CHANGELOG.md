## [1.1.0]

### Безопасность

- **Цены больше не берутся из cookie.** Корзина очищается `as_sanitize_cart()`, цена всегда читается из базы через `as_get_product_price()` — на витрине, при оформлении и в письмах. Неопубликованные и удалённые товары выпадают из корзины.
- **Обязательные поля проверяются на сервере** (`as_get_required_fields()`), значение `required` из браузера игнорируется. Шаблоны темы берут список полей из той же функции.
- **Файлы заказа:** все проверки — до сохранения (не больше 3 файлов, 5 МБ на файл, 15 МБ всего, белый список расширений, проверка реального типа файла). Файлы хранятся в закрытой папке `uploads/argon-shop-private/` и удаляются после отправки писем. Старая публичная папка `uploads/order-files` удаляется миграцией.
- **Регистрация при оформлении:** пароль больше не отправляется по почте — покупатель получает ссылку для установки пароля. Для регистрации нужен email.
- Проверка nonce добавлена во все AJAX-действия (у очистки корзины и фильтра заказов в кабинете её не было).
- Поиск: запросы к базе через `$wpdb->prepare()`.
- Экранирование вывода на странице каталога; проверка значения cookie сортировки.
- Личный кабинет: AJAX-запросы от гостей отклоняются.

### Изменено

- **Минимальные требования повышены: PHP 8.3 и WordPress 7.1** (были PHP 7.4 и WordPress 6.0): заголовки `Requires PHP` / `Requires at least` в `argon-shop.php` и `style.css` темы, README, документация для ИИ. На более старых версиях WordPress не активирует плагин и тему.
- README: удалён раздел «Статус и ограничения»; восстановлено правило nginx для защиты закрытых файлов заказов, потерянное при удалении раздела.
- POSITIONING.md: удалена повторяющаяся строка «Vanilla JS, без фреймворка» в разделе 4.
- `AGENTS.md`: таблица инструментов (что каждый читает автоматически, в том числе Claude Code через `CLAUDE.md`).

- **Все комментарии в коде и документация переведены на английский** (`README.ru.md` оставался русским переводом README). В ветке `ru` комментарии и документация снова на русском, см. [Unreleased].
- Маркер запятой в формате полей формы в «Настройки → Магазин» теперь `/comma/`; старый `/запятая/` продолжает работать.
- Шорткоды `[contact-form-7]` в теме используют `title="Feedback"` (заголовок не выводится, форма выбирается по `id`).
- Шаблоны переводов (`.pot`) пересозданы; `.po`/`.mo` обновлены для новых строк.

- **Версия хранится только в `argon-shop.php` (заголовок и `ARGON_SHOP_VERSION`) и в `style.css` темы.** Теги `@version` удалены из файлов; новые функции получают `@since`.
- Стили и скрипты темы подключаются с версией темы (`?ver=`), поэтому браузеры обновляют их после обновления темы.
- Заголовки плагина и темы и названия шаблонов страниц («Template Name») — на английском и переводятся через `.po`. Привязка шаблонов к страницам не меняется (WordPress хранит имя файла).
- Поля формы по умолчанию создаются при активации на языке сайта.
- Хлебные крошки: строки переводятся при выводе (`AS_Kama_Breadcrumbs::default_l10n()`), фильтр `kama_breadcrumbs_default_loc` работает как раньше.

- `shoppingCart.php` (~1200 строк) разделён на модули: `cart-ajax.php`, `checkout.php`, `checkout-fields.php`, `checkout-files.php`, `checkout-registration.php`, `checkout-emails.php`.
- **Все функции плагина получили префикс `as_`** (119 функций; класс `Kama_Breadcrumbs` → `AS_Kama_Breadcrumbs`). Старые имена публичного API работают через `includes/legacy-functions.php`. Таблица соответствия — `docs/ai/AI_FUNCTION_NAMES.md`. Имена AJAX-действий, хуков, CSS-классов, мета-полей и опций не менялись.
- Тема: заголовок `Theme Name: Argon Shop Theme`, версия 1.1.0, `Requires PHP: 7.4`.

### Исправлено

- Доработка защиты от регрессий: единый строгий контракт PHP/JS (полное число, корректная группировка тысяч, научная запись, только конечные значения); некорректный ввод возвращает ноль. Вес в корзине читается через `parseNumber()`. Карточки каталога и страница товара используют `as_get_product_price()` с его фильтром. Новый помощник и его отметки включены в релиз `1.1.0`.
- Общие числовые фикстуры; изолированные PHP-тесты реальных функций с заглушками WordPress; JS-тесты; токенизированные проверки с тестами намеренно испорченного кода. Smoke-тест расширен: дробные цены/пороги, суммы на границе, порядок ступеней, AJAX-итог, пароли с кавычками/слешами, текущий «0», короткий новый «0», длина UTF-8 и несовпадение подтверждения.
- Оптовые цены: `60,33` больше не обрезается до `60`; добавлена `as_to_float()` для десятичной запятой, пробелов и смешанных разделителей. Цены и названия ступеней читаются единообразно; ступень ищется по числовому значению, выбирается наибольшая достигнутая независимо от порядка массива. Исправлены сравнение текущей ступени в теме и запасное чтение цены в корзине.
- Личный кабинет: пароли больше не проходят через `sanitize_text_field()`; после проверки строкового типа применяется только `wp_unslash()`. Сохраняются теги, `%xx` и повторяющиеся пробелы; пустота проверяется строго, длина нового пароля считается в символах UTF-8.
- Защита от повторения: секция 12 smoke-теста (общие числовые примеры, реальные ступени и пароли), секция 7 static-check; связанные правила добавлены в актуальную русскую документацию без восстановления старых `*.ru.md` и `docs/ai/ru/`.
- Документация для ИИ сверена с кодом: расположение функций (`as_get_product_price`, `as_sort`, `as_getClassActiveItem`, `assets/js/shared/`, `includes/api/getData/`), проверки прав в AJAX-действиях админки (`manage_options`, а не «TODO»), пример проверки прав (останавливает запрос через `wp_die()`), обработка ошибок кабинета (без JSON и кода 403).
- Форматы ответов: `wp_send_json()` в проекте не используется (`echo wp_json_encode()` + `wp_die()`); при удалении товара возвращается сама карта цен, без обёртки; в `edited` / `errors` кабинета — переведённые сообщения; `arsCartWidget.clear()` после заказа не вызывается.
- Поиск: полное ранжирование (1000/800/500/400/50/30/10/5) и `posts_distinct`; сортировка: `#showResult`, значения `typeSort`.
- Неиспользуемые cookie `WP-LastViewedPosts` и неподключаемый `last_viewed_posts.php`; список модулей `main.js`; зависимость скриптов темы от плагина; Fancybox больше не используется; nonce заказа выводится inline-скриптом; функции без префикса `as_`; версии форков и библиотек; уведомление об авторских правах.
- Шаблоны городов (`*-aktsii-istra.php`) помечены как ещё не созданные. `single.php` по-прежнему вызывает `get_template_part( 'single-aktsii-istra.php' )` с расширением `.php` — описано в `AI_TEMPLATE_MAP.md`, в коде не менялось.

- **Русские тексты на английских и французских сайтах**, пропущенные в 1.1.0, потому что были зашиты в JS: «ЗАГРУЖЕНО ФАЙЛОВ» в корзине, ошибки лимита файлов, «Корзина пуста», серверные ошибки корзины и оформления, «Ищем результаты...», подтверждение формы обратной связи, ошибки кабинета и страницы товара, тексты галереи в админке, модальное окно темы («Закрыть», «Загрузка…», ошибка загрузки).

- Фатальная ошибка при оформлении заказа с пустой корзиной — теперь выводится сообщение «Корзина пуста».

### Обновление с 1.0.0

- Перед обновлением проверьте хостинг: нужны PHP 8.3+ и WordPress 7.1+.

- **Магазины в рублях: откройте «Настройки → Магазин» и выберите «Российский рубль (₽)» в поле «Валюта», затем сохраните.** Валюта по умолчанию — USD, без этого шага цены выводятся со знаком `$`. Русские тексты не изменились: рубль по-прежнему выводится как «Р» (`Р/шт`); прежние подписи «руб»/«руб.» в «Недавно просмотренных» и в итоге по товару теперь тоже «Р».
- Собственный код, выводивший `₽` рядом с ценами, должен использовать `as_price_html()` (плагин) или `astheme_price_html()` (тема).
- Миграция базы данных не нужна.

- **nginx:** закройте папку файлов заказов — `location ^~ /wp-content/uploads/argon-shop-private/ { deny all; }` (для Apache достаточно автоматически создаваемого `.htaccess`).
- Если ваш код (дочерняя тема, сниппеты) использует **внутренние** функции плагина — например, как колбэк в `add_action` / `add_filter` / `remove_action`, — переименуйте их по таблице `docs/ai/AI_FUNCTION_NAMES.md`. Функции, вызываемые из шаблонов, продолжают работать под старыми именами.
- Покупатели заметят: письмо со ссылкой вместо пароля, черновики и неопубликованные товары исчезают из корзины, лимиты файлов проверяет сервер.
