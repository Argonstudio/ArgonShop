# AI_I18N.md — переводы (английский, русский, французский)

Продолжение [AI.md](../../AI.md). Переводы следуют правилам WordPress.

## 1. Как это работает

- **Исходный язык кода — английский.** Все тексты в PHP пишутся на английском внутри функций перевода. Русский и французский — переводы.
- **Комментарии и документация в RU-ветке — на русском**. `tests/static-check.php` (проверка 6) разрешает кириллицу в комментариях PHP и в комментариях JS/CSS; кириллица в коде JS/CSS по-прежнему запрещена.
- Язык определяется настройкой WordPress «Язык сайта» (для админки — «Язык» пользователя в профиле).
- Для языков без перевода выводится английский текст.

| | Плагин | Тема |
|---|---|---|
| Text Domain | `argon-shop` | `argon-shop-theme` |
| Папка | `plugins/argon-shop/languages/` | `themes/argon-shop-theme/languages/` |
| Шаблон | `argon-shop.pot` | `argon-shop-theme.pot` |
| Русский | `argon-shop-ru_RU.po` / `.mo` | `ru_RU.po` / `.mo` |
| Французский | `argon-shop-fr_FR.po` / `.mo` | `fr_FR.po` / `.mo` |
| Загрузка | `as_load_textdomain()` в `argon-shop.php` (`init`) | `astheme_load_textdomain()` в `functions.php` (`after_setup_theme`) |

Имена файлов темы содержат только локаль (`ru_RU.po`), у файлов плагина есть префикс домена. Это правило WordPress, не переименовывайте их.

Переводы в `wp-content/languages/plugins/` и `wp-content/languages/themes/` имеют приоритет: сайт может переопределить любую строку, не трогая плагин.

## 2. Тексты в JavaScript

В JS-файлах **нет видимых пользователю текстов ни на каком языке, кроме английских запасных значений**. Переведённые тексты приходят из PHP:

| Скрипт | Глобальный объект | Где формируется | Как читает JS |
|---|---|---|---|
| `ars-main` (ES-модули фронтенда) | `arsWpAjax.i18n` | `argon_shop_js_i18n()` в `argon-shop.php` (фильтр `argon_shop_js_i18n`) | `t( key, ...args )` из `assets/js/interface/core/config.js` |
| `ars-gallery-js` (галерея в админке) | `arsGalleryI18n` | `as_add_admin_styleScript()` в `argon-shop.php` | `i18n.*` в `gallery.js` |
| `ars-modal-js` (модальное окно темы) | `arsModalI18n` | `astheme_scripts()` в `functions.php` темы | `i18n.*` в `modal.js` |

Добавление текста на фронтенде:

1. Добавьте ключ с английским текстом в `I18N_DEFAULTS` в `core/config.js`.
2. Добавьте тот же ключ с `__( '…', 'argon-shop' )` в `argon_shop_js_i18n()` (с комментарием `translators:`, если есть подстановки).
3. Используйте `t( 'key' )` в модуле (`import { t } from '../core/config.js';`). Подстановки: `t( 'fileTooBig', name, maxMb )` для `'The file "%1$s" exceeds %2$s MB.'`.
4. Обновите `.pot`/`.po`/`.mo` (раздел 4).

Сообщения, которые сервер возвращает в AJAX-ответах, уже переведены в PHP.

## 3. Правила для кода

```php
// Текст в HTML
<?php esc_html_e( 'Add to cart', 'argon-shop' ); ?>
// Текст в атрибуте
placeholder="<?php esc_attr_e( 'Your comment', 'argon-shop-theme' ); ?>"
// Текст в переменной / в AJAX-ответе
$message = __( 'Your cart is empty. Add products and try again.', 'argon-shop' );
// Подстановки — только через sprintf, с комментарием для переводчика
/* translators: %s: order number. */
sprintf( __( 'Order #%s', 'argon-shop' ), $number );
// Одно английское слово с разными значениями — контекст
_x( 'Price', 'sort by', 'argon-shop-theme' );
// Число + слово — формы множественного числа (в русском их три)
sprintf( _n( '%d product', '%d products', $count, 'argon-shop' ), $count );
```

Запрещено:

- **Писать видимый пользователю текст без функции перевода** — ни по-русски, ни по-английски (для JS — см. раздел 2).
- **Склеивать фразу из кусков:** `'File "' . $name . '" is larger than '` — переводчик не сможет поменять порядок слов. Используйте `sprintf` с `%1$s`, `%2$s`.
- **Передавать в `__()` переменную или выражение** — инструменты не смогут извлечь строку. Только литерал: `__( 'Text', 'argon-shop' )`.
- **Путать домены:** файлы плагина используют `'argon-shop'`, файлы темы — `'argon-shop-theme'`. Вызов без домена недопустим (это домен ядра WordPress).
- **Переводить данные:** ключи массивов и мета-полей, `name`/`value` полей форм, имена AJAX-действий, CSS-классы. Переводится только то, что видит человек.
- **Создавать `.l10n.php`**, не обновляя его при каждом изменении: WordPress 6.5+ предпочитает его файлу `.mo`, и устаревший `.l10n.php` перекрывает свежий перевод. Проект поставляет только `.po`/`.mo`.
- **Хардкодить знак валюты.** Цены выводятся через `as_price_html()` / `astheme_price_html()` (см. AI_EXTENDING.md, «Валюта»).

Намеренные исключения (русский в коде — это данные, а не интерфейс) перечислены в `$cyr_allow` / `$cyr_allow_files` в `tests/static-check.php`: старый маркер запятой `/запятая/` (по-прежнему принимается наряду с `/comma/`), ключ `"Название компании"` в сохранённых данных пользователя и карты раскладок клавиатуры в `includes/interface/search/searchLanguage.php`.

Тексты, которые вводит владелец магазина (названия полей форм в «Настройки → Магазин», товары, страницы), хранятся в базе данных и переводятся мультиязычным плагином (Polylang, WPML), а не файлами `.po`.

## 4. Добавили или изменили текст — обновите переводы

Изменение английской строки = новая строка: старый перевод к ней не применяется.

**С терминалом и WP-CLI** (из корня репозитория):

```bash
# 1. Шаблоны .pot из кода
wp i18n make-pot plugins/argon-shop plugins/argon-shop/languages/argon-shop.pot --domain=argon-shop --exclude=assets/vendor
wp i18n make-pot themes/argon-shop-theme themes/argon-shop-theme/languages/argon-shop-theme.pot --domain=argon-shop-theme --exclude=assets/vendor
# 2. Новые строки в файлы .po (существующие переводы сохраняются, устаревшие удаляются)
wp i18n update-po plugins/argon-shop/languages/argon-shop.pot
wp i18n update-po themes/argon-shop-theme/languages/argon-shop-theme.pot
# 3. Заполните msgstr новых строк во всех файлах .po (ru_RU и fr_FR)
# 4. Скомпилируйте файлы .mo
wp i18n make-mo plugins/argon-shop/languages
wp i18n make-mo themes/argon-shop-theme/languages
# 5. Проверка
php tests/static-check.php
```

**Без терминала** (ИИ в чате правит отдельные файлы): ИИ пишет код с `__()` и в ответе даёт таблицу «английский → русский → французский» для новых строк. Пользователь открывает `.pot`/`.po` в [Poedit](https://poedit.net/) («Перевод → Обновить из POT-файла»), заполняет переводы и сохраняет — Poedit сам создаёт `.mo`. ИИ без терминала не правит `.mo` (это бинарный файл).

## 5. Качество перевода

- Русский перевод должен совпадать с тем, что сайт показывал до перехода на английский: русские сайты выглядят как раньше. Изменение русской формулировки — это правка `.po`, а не кода.
- Французский: неразрывный пробел перед `: ; ! ?` допустим, но в проекте используется обычный пробел — соблюдайте один стиль. Кавычки — « ».
- Подстановки (`%s`, `%1$s`, `%d`) в переводе те же, что в оригинале. `tests/static-check.php` это проверяет.
- Валюта — настройка магазина (Настройки → Магазин → Валюта: USD, EUR, RUB), а не перевод. Через перевод проходит только знак рубля (`msgid "₽"`, по-русски: «Р»).

## 6. Поиск и язык сайта

Правила поиска зависят от языка сайта (`as_search_language()` в `includes/interface/search/searchLanguage.php`): `ru` — исправление раскладки QWERTY → ЙЦУКЕН (как до 1.1.0); `en` — русская раскладка → QWERTY, английские стоп-слова и окончания множественного числа; `fr` — русская раскладка → AZERTY, замены QWERTY ↔ AZERTY, элизии, французские стоп-слова и множественное число. Остальные локали используют правила `en`. Фильтры: `argon_shop_search_language`, `argon_shop_search_stop_words`, `argon_shop_search_layout_variants`.

## 7. Новый язык

1. Скопируйте `.pot` в `argon-shop-xx_XX.po` (плагин) и `xx_XX.po` (тема), заполните `Language` и `Plural-Forms` в заголовке.
2. Переведите, скомпилируйте `.mo` (`wp i18n make-mo` или Poedit).
3. Добавьте язык в проверки `tests/static-check.php` (массив `array( 'ru_RU', 'fr_FR' )` в разделе 4) и в таблицу раздела 1 этого файла.
4. Если языку нужны собственные правила поиска (стоп-слова, раскладка клавиатуры), добавьте их в `searchLanguage.php` или через фильтры из раздела 6.
5. Запись в `CHANGELOG.md` → «Добавлено».
