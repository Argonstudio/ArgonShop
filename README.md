# Argon Shop (2018)

**Argon Shop** — это легковесный, высокооптимизированный плагин интернет-магазина для WordPress, автор Иван Войтков, 2018 год. Плагин спроектирован по принципу «минимального оверхеда»: он написан в нативном стиле ядра WordPress, не использует тяжелых сторонних фреймворков или библиотек и обеспечивает максимальную скорость работы.


---

## ⚡ Ключевые преимущества и архитектура

### 1. Экстремальная скорость и оптимизация под Big Data (50k+ товаров)
* **Минимальное потребление ресурсов:** Магазин с активным плагином загружается практически мгновенно, не создавая нагрузки на сервер. Это позволяет разворачивать крупные проекты на обычном недорогом хостинге.
* **Работа с большими каталогами:** Архитектура ядра оптимизирована для поддержки **более 50 000 товаров**, категорий и множества характеристик без замедления времени ответа базы данных.
* **Показатели Google PageSpeed Insights:** 99/100 на десктопах и 100/100 на мобильных устройствах (индекс скорости загрузки — всего 900 мс).

### 2. Полная UI/UX независимость (Архитектура шаблонизации)
В отличие от крупных e-commerce плагинов, жестко вшивающих HTML-структуру корзины и личного кабинета (ЛК) в свой код, **Argon Shop делегирует верстку теме сайта**.
* Разработчик имеет полную свободу: для интеграции функционала плагина достаточно просто прописать предопределенные плагином HTML-аттрибуты (`data-product-id`), ID полей (для вывода ошибок, кнопок) и AJAX-селекторы прямо в шаблонах темы.
* Компоновка элементов, CSS-классы и дизайн могут быть абсолютно любыми.

### 3. Интеллектуальный поиск без перезагрузки (Native AJAX)
* Полностью самописный JS/PHP-модуль «живого» поиска.
* Поддерживает **автоматическое исправление ошибочной раскладки клавиатуры**.
* Реализована мульти-категорийная выдача результатов в одной плашке: плагин одновременно ищет совпадения по товарам, категориям каталога, акциям, новостям и статьям. Настройки областей поиска гибко управляются из админки.

### 4. Динамическое Мега-Меню (Алгоритм балансировки столбцов)
* Плагин ориентирован на глубокую вложенность категорий (4 уровня и более).
* Чтобы избежать визуального перекоса по высоте при выводе сложного дерева категорий в 3 столбца, в плагин интегрирован **алгоритм расчета высоты блоков**. Функция автоматически группирует разноразмерные родительские и дочерние элементы так, чтобы столбцы получались максимально близкими друг к другу по высоте.

### 5. Мульти-городская архитектура (Single Admin Panel)
* Альтернатива громоздкому WordPress Multisite. Плагин позволяет управлять каталогом для нескольких городов **внутри единой админ-панели и общей базы данных**.
* Данные (например, уникальные описания товаров для Москвы, Истры и т.д., а также SEO-параметры) редактируются на одной странице друг под другом.
* При этом сохраняется полная совместимость и со стандартным WP Multisite для масштабных федеральных сетей.

### 6. Собственная AJAX-система характеристик (Аналог ACF до его релиза)
* Разработан собственный каталог характеристик с привязкой к уровням категорий. В 2018 году данный функционал опережал аналогичные решения (в ACF подобное появилось значительно позже).
* При редактировании товара список характеристик на странице обновляется динамически через AJAX сразу после выбора категории.
* Поддерживается два типа характеристик: строковые текстовые поля и сложные древовидные опции (выбор да/нет, списки), формирующиеся через родительские и дочерние связи.

## 🛒 E-commerce функционал «из коробки»
* **Умная система оптовых цен:** Поддержка до 4 шагов оптовых цен с автоматическим пересчетом скидки по AJAX прямо в корзине при достижении определенной суммы заказа.
* **Личный кабинет (ЛК) на AJAX:** Обновление персональных данных (физ. лица / юр. лица), управление настройками безопасности (смена e-mail, пароля) и отслеживание статусов заказов без перезагрузки страниц.
* **Гибкий конструктор форм оформления заказа:** Настройка полей, плейсхолдеров и адаптивных CSS-классов (100% ширины / 50% ширины) для 3 типов форм (Краткая, Физ. лица, Юр. лица) напрямую из панели управления.
* **Валидация данных и прикрепление файлов:** Встроенная проверка корректности ввода (телефон, email, длина пароля) и продвинутый модуль загрузки файлов (с контролем веса, формата и выводом мета-данных пользователю).
* **Панель менеджера:** Кастомный интерфейс управления заказами со сменой статусов («Новый», «В обработке», «Выполнен»), AJAX-поиском товаров для добавления в чек, фильтрацией и массовым удалением.
* **100% Адаптивность:** Как фронтенд-модули (интерактивный тач-слайдер галереи товаров, мега-меню, формы), так и кастомные экраны панели администратора полностью адаптированы под любые мобильные разрешения.

## 🛠 Технологический стек
* **Backend:** PHP (Native WordPress API, Кастомные типы записей / Таксономии / Мета-поля / AJAX-обработчики).
* **Frontend:** JavaScript (Vanilla JS / jQuery для AJAX-операций, анимаций интерфейса, логики корзины и живого поиска).
