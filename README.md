# ArgonShop версия 2018 года

Плагин интернет-магазина. Изначальная версия плагина 2018 года, для Wordpress 4.9, PHP 5.6 и Jquery 2.2 

Использовались JS библиотеки Fancybox и Slick в теме.

Код исторический и сейчас нигде не используется.

Сайт-пример [https://plugin.argon-studio.ru/](https://plugin.argon-studio.ru/) , в примере новая версия, тем ни менее они похожи. При обновлении тема почти не изменилась, я переписал только код. 

Серьезные отличия в работе поиска на отдельной странице поиска и в работе слайдеров, в остальном по мелочи или в закрытой части(в панели администратора). 
В панели администратора в новой версии были улучшены заказы и сделан собственный модуль для прикрепления картинок.
