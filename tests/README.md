# Тесты ArgonShop

| Файл | Запуск | Требования |
|---|---|---|
| `static-check.php` | `php tests/static-check.php` | только PHP 8.3+ |
| `smoke-test.php` | `wp eval-file tests/smoke-test.php` | тестовый WordPress + WP-CLI |

Что и когда запускать, как менять тесты и ручной чек-лист — [docs/ai/AI_TESTING.md](../docs/ai/AI_TESTING.md).

## static-check.php — проверки без WordPress

Запускается из корня репозитория за несколько секунд; сайт и база не нужны:

```bash
php tests/static-check.php
```

Разделы:

1. **Синтаксис PHP** всех файлов плагина и темы.
2. **Тексты без перевода** — никакого видимого пользователю текста вне функций перевода.
3. **Text domain** — `argon-shop` в плагине, `argon-shop-theme` в теме.
4. **Переводы** — `.pot` соответствует коду, каждая строка переведена на русский и французский (с теми же подстановками `%s`).
5. **Версии** — версия совпадает в `argon-shop.php`, `ARGON_SHOP_VERSION` и `style.css`, а в `CHANGELOG.md` есть раздел для неё.
6. **Язык исходников** (с 1.1.0) — не даёт русским строкам вроде «Загружено файлов» вернуться в JS. В этой ветке `ru` кириллица разрешена в комментариях PHP и в комментариях JS/CSS, но запрещена в коде JS/CSS. (В английской ветке `main` кириллицы нет ни в комментариях PHP, ни в JS/CSS.)

Код выхода `0` — всё в порядке.

В Claude Code эта проверка запускается автоматически после каждой правки PHP-файла (хук в `.claude/settings.json`) и вручную командой `/check`.

## smoke-test.php — сквозная проверка магазина

Прогоняет основные сценарии на настоящем WordPress «как браузер» (HTTP-запросы к сайту) и после себя удаляет все тестовые данные.

**Что проверяется:** добавление в корзину, изменение количества, удаление и очистка; подмена цены в cookie; обязательные поля (в том числе снятие `required` в браузере); загрузка файлов (PHP-скрипт под видом `.jpg`, файл больше 5 МБ, обычный PNG и закрытое хранилище); создание заказа и письма; регистрация при оформлении (в письме нет пароля, вместо него ссылка для установки); личный кабинет (гости отклоняются); поиск со спецсимволами; языковые правила поиска для ru/en/fr (исправление раскладки, стоп-слова, множественное число, элизии); основные страницы сайта и админки; строки JS приходят из переводов (`arsWpAjax.i18n`), а на странице корзины нерусского сайта нет кириллицы; настройка валюты (символы и положение USD/EUR/RUB); AJAX-пересчёт заказа в админке; новые ошибки PHP в `debug.log`.

### Требования

- Тестовый или локальный сайт — **не боевой**: тест создаёт и удаляет товары, заказы и пользователей.
- [WP-CLI](https://wp-cli.org/).
- Активны плагин `argon-shop` и тема `argon-shop-theme`.
- Сайт отвечает на запросы с того же сервера (адрес из `siteurl`).
- В `wp-config.php`:

```php
define( 'WP_ENVIRONMENT_TYPE', 'local' );   // без этого WordPress считает сайт боевым, и тест не запустится
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );             // для проверки debug.log
define( 'WP_DEBUG_DISPLAY', false );
```

### Запуск

```bash
cd /path/to/wordpress
wp eval-file /path/to/ArgonShop/tests/smoke-test.php
```

Код выхода `0` — все проверки пройдены, `1` — есть ошибки (перечислены в выводе). Принудительный запуск на сайте боевого типа — `ARGON_SHOP_SMOKE_FORCE=1` (не рекомендуется).

Во время теста письма с сайта не уходят: временный mu-плагин перехватывает `wp_mail` и удаляется после теста. Валюта магазина восстанавливается после проверок валюты.

### Перед коммитом

```bash
php tests/static-check.php
wp eval-file tests/smoke-test.php
```

Тест не зависит от языка сайта: запускайте его на русском, французском и английском сайтах (`wp site switch-language ru_RU|fr_FR|en_US`). Раздел «11. Translations» проверяет, что выбранный язык действительно загружен; раздел «8. Search language» подбирает случаи для текущего языка.

Добавили функцию — добавьте проверку в `smoke-test.php` (функция `as_smoke_check( $condition, 'описание' )`).

## Дополнительные регрессионные проверки

- `php tests/regression-check.php` — реальные функции плагина с заглушками WordPress; PHP 8.3+ и mbstring. Запускается также секцией 7 static-check.
- `node tests/number-check.mjs` — реальный JS-парсер и общие примеры `number-cases.json`; Node 18+.
- `wp eval-file tests/smoke-test.php` — секция 12 проверяет оптовые цены и пароли в реальном WordPress.

Токенизированные проверки игнорируют пробелы/комментарии; тесты намеренно испорченного кода проверяют обнаружение `floatval ( $stepPrice )` и санитайзеров с комментариями. Изолированные тесты не заменяют smoke на тестовом сайте.
