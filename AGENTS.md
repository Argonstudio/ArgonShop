# AGENTS.md

> Полный контекст проекта для ИИ-ассистентов — в файлах `AI_CONTEXT.md`
> и связанных с ними документах.

## Зачем этот файл

Разные ИИ-ассистенты ищут разные имена файлов с контекстом:

| Инструмент | Ожидаемое имя |
|------------|---------------|
| Cursor | `.cursorrules` |
| Claude Code | `CLAUDE.md` |
| OpenAI Codex | `AGENTS.md` ← этот файл |
| Aider, Windsurf, универсально | `AI.md` |

Во избежание дублирования **весь контекст лежит в `AI_CONTEXT.md` и `AI_*.md`**.
Этот файл — короткий указатель.

## Порядок чтения

1. **`AI_CONTEXT.md`** (корень) — точка входа: карта репозитория, ключевые сущности, технологии.
2. **`plugins/argon-shop/AI_CONTEXT.md`** — плагин: модули, API, AJAX, легаси-проблемы.
3. **`themes/bmshop/AI_CONTEXT.md`** — тема: шаблоны, ресурсы, зависимости от плагина.
4. **`docs/AI_DATA_FLOWS.md`** — сквозные сценарии (плагин + тема).
5. **`plugins/argon-shop/docs/AI_AJAX_REFERENCE.md`** — справочник AJAX-экшенов.
6. **`themes/bmshop/docs/AI_TEMPLATE_MAP.md`** — карта «URL → шаблон → функции».

> Если задача — правка в конкретной области, читай `AI_CONTEXT.md` +
> нужный специализированный файл.

## Короткие правила

- **jQuery на фронтенде разрешён.** Историческая ветка построена на jQuery 2.2.2
  и PHP 5.6. Не предлагай ES6+ / Vanilla JS без явного запроса на миграцию.
- **Не менять DOM-селекторы и AJAX-действия** без синхронной правки PHP и JS.
- **Не менять формат метаполей и куки** — есть уже залитые данные.
- **ACF-поля обязательны.** Галерея товара хранится в `slider_imgs`
  (comma-separated ID) — см. `README.md`.
- **Разделение слоёв:** логика в плагине, вёрстка в теме.
- **Тема не самодостаточна** — она напрямую вызывает функции плагина.
