# AGENTS.md

> Полный контекст проекта для ИИ-ассистентов — в файле [`AI.md`](AI.md) и связанных с ним документах.

## Зачем этот файл

Разные ИИ-ассистенты ищут разные имена файлов с контекстом:

| Инструмент | Ожидаемое имя |
|------------|---------------|
| Cursor | `.cursorrules` |
| Claude Code | `CLAUDE.md` |
| OpenAI Codex | `AGENTS.md` ← этот файл |
| Aider, Windsurf, универсально | `AI.md` |

Во избежание дублирования **весь контекст лежит в `AI.md` и `AI_*.md`**.
Этот файл — короткий указатель.

## Порядок чтения

1. **`AI.md`** — индекс, ключевые контракты, жёсткие запреты.
2. **`AI_ARCHITECTURE.md`** — слои, модули, карта папок.
3. **`AI_DATA_FLOWS.md`** — сценарии данных.
4. **`AI_AJAX_REFERENCE.md`** — AJAX-действия.
5. **`AI_TEMPLATE_MAP.md`** — шаблоны темы.
6. **`AI_EXTENDING.md`** — как добавлять фичи.

> Если задача — правка в конкретной области, читай только `AI.md` + нужный
> специализированный файл.

## Короткие правила

- **jQuery на фронтенде запрещён.** Только Vanilla JS и ES-модули.
- **Не менять DOM-селекторы и AJAX-действия** без синхронной правки PHP и JS.
- **Не менять формат метаполей и куки** — есть уже залитые данные.
- **Разделение слоёв:** логика в плагине, вёрстка в теме.

---

> ⚠️ **Для ветки `historic/php56-jquery`:** правило «jQuery запрещён» **не действует**.
> Историческая версия построена на jQuery 2.2 и PHP 5.6. Актуальные правила
> из этого файла применимы к современной версии плагина. См. `README.md`
> и `AI_CONTEXT.md` для деталей по исторической ветке.
